门面模式(command pattern)

发表于 2015-09-29 更新于 2025-12-05 阅读次数： 本文字数： 406 阅读时长 ≈ 1 分钟

命令模式就是将一组对象的相似行为，进行了抽象，将调用者与被调用者之间进行解耦，提高了应用的灵活性。命令模式将调用的目标对象的一些异构性给封装起来，通过统一的方式来为调用者提供服务。
